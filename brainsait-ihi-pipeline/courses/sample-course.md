# Evidence-Based Clinical Practice

Learn how to evaluate evidence, translate findings into practice, and improve clinical outcomes.

## Learning objectives

- Identify high-value sources of evidence.
- Translate evidence into safe bedside practice.
- Document an implementation plan for your team.

This sample course is used to validate the BrainSAIT IHI conversion pipeline end to end before running the full production migration.
