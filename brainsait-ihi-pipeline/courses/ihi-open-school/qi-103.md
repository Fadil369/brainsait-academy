# Testing and Measuring Changes with PDSA Cycles

**QI 103: اختبار وقياس التغييرات باستخدام دورات PDSA**

## Overview

Learn the basic concepts to run successful PDSA (Plan-Do-Study-Act) cycles in a clinical setting.

## نظرة عامة

learn المفاهيم الأساسية لتشغيل دورات PDSA (التخطيط-التنفيذ-الدراسة-الفعل) الناجحة في بيئة سريرية.

Upon completion of this course, learners will be able to:
